What happens when someone registers

  1. They enter their email on the public Video Conference page.
  2. The server stores the request and emails the room link.
  3. They appear in the Registrations tab.
  4. No manual sending is needed.

The FreeConferenceCall link is only a backup. Jitsi’s free public server currently limits a meeting to 95 minutes; clear the Jitsi room and use the backup for a longer service.

Step by step

How to run the meeting

  1. Set the Jitsi room in Meeting details. Use the Generate button if you want a private-looking room name, then save.
  2. Share the Video Conference page with the church. People request the link by email and receive it automatically.
  3. Join at meeting time by opening the Video Conference page and pressing Join the meeting. The room opens in the browser.
  4. Join first if possible so the pastor can welcome people and keep order. If the pastor is late, the room still starts for everyone else.
  5. The backup link is only for a large service or if Jitsi is unavailable. Leave it blank unless the church needs it.

No account and no app are needed for Jitsi. The free public server limits a meeting to 95 minutes and is provided as-is; the FreeConferenceCall link is the backup for longer or larger services.

Email check

Send a test email

Use this once after setup. If the test arrives, registration emails will work too.

If email does not arrive

  • Check the spam or promotions folder.
  • Make sure RESEND_API_KEY or the SMTP_* values are set on Render.
  • For Gmail, use a 16-character App Password, not the normal account password.
  • Ask the person who manages the server to check the Render logs.

For safety, sign out when using a shared phone or computer.
